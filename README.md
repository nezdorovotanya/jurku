# юрку

Сайт [jurkujurku.com](https://jurkujurku.com): кухни, мебель и одноэтажные каркасные дома из берёзовой фанеры. Петербург и Ленобласть.

Клиент собирает кухню, фасады или дом в 3D-конструкторе, видит предварительную цену и оставляет имя и телефон. Заявка вместе со всем, что он собрал, приходит в Telegram-бот [@jurkupietari_bot](https://t.me/jurkupietari_bot).

## Что здесь лежит

| Файл | Что это |
|---|---|
| `index.html` | Весь сайт одним файлом: страница, стили, 3D-конструктор. Цены считает сервер |
| `assets/` | three.js для 3D и шрифт Inter. Лежат здесь, а не на внешних CDN, чтобы сайт открывался в России без задержек |
| `og.png` | Картинка для превью ссылки в мессенджерах |
| `CNAME` | Домен для GitHub Pages |

Здесь только клиентская версия. Чертежи, экономика, список инструмента и закупочные цены в этот репозиторий не попадают.

## Цены и заявки

В этом репозитории цен нет. Сайт отправляет выбор клиента на `https://api.jurkujurku.com/price` и показывает цену, которую вернул сервер. Заявка уходит на `https://api.jurkujurku.com/order`, сервер пересчитывает цену и присылает её в Telegram-бот [@jurkupietari_bot](https://t.me/jurkupietari_bot) вместе с себестоимостью и наценкой для владельца.

Сервер, цены и наценки лежат в отдельном приватном репозитории `jurku-worker`. Цены меняются там, в `src/prices.json`.

Контакты на сайте (телефон и Telegram для запасного пути, если сервер недоступен) — в строке `<script id="app-site">window.SITE =` в `index.html`.
