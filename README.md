# юрку

Сайт [jurkujurku.com](https://jurkujurku.com): кухни, мебель и одноэтажные каркасные дома из берёзовой фанеры. Петербург и Ленобласть.

Клиент собирает кухню, фасады или дом в 3D-конструкторе, видит предварительную цену и оставляет имя и телефон. Заявка вместе со всем, что он собрал, приходит в Telegram-бот [@jurkupietari_bot](https://t.me/jurkupietari_bot).

## Что здесь лежит

| Файл | Что это |
|---|---|
| `index.html` | Весь сайт одним файлом: страница, стили, конструктор, цены |
| `assets/` | three.js для 3D и шрифт Inter. Лежат здесь, а не на внешних CDN, чтобы сайт открывался в России без задержек |
| `og.png` | Картинка для превью ссылки в мессенджерах |
| `CNAME` | Домен для GitHub Pages |

Здесь только клиентская версия. Чертежи, экономика, список инструмента и закупочные цены в этот репозиторий не попадают.

## Как поменять цены и контакты

На сайте нет панели управления: всё, что лежит в странице, видно любому посетителю, поэтому настройки меняются только через этот репозиторий.

1. Открыть `index.html` на GitHub, нажать карандаш (Edit).
2. Найти строку, которая начинается с `<script id="app-site">window.SITE =`. В ней цены (`model`) и контакты (`contacts`).
3. Поменять числа или телефон, нажать Commit changes. Через минуту сайт обновится.

## Заявки в Telegram

Форма отправляет имя, телефон и собранный проект на `https://api.jurkujurku.com/order`. Это Cloudflare Worker из папки `worker/`: он проверяет заявку и пересылает её боту [@jurkupietari_bot](https://t.me/jurkupietari_bot). Токен бота и чат хранятся только в секретах воркера, в коде сайта их нет.

Защита от спама в воркере: заявки принимаются только со страниц jurkujurku.com, не больше 5 с одного адреса за 10 минут, имя и телефон проверяются, скрытое поле отсекает ботов.

Если токен когда-нибудь утечёт: @BotFather → /revoke → новый токен вписать в секрет `BOT_TOKEN` воркера.
