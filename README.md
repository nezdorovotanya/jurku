# юрку

Сайт [jurkujurku.com](https://jurkujurku.com): кухни, мебель и одноэтажные каркасные дома из берёзовой фанеры. Петербург и Ленобласть.

Клиент собирает кухню, фасады или дом в 3D-конструкторе, видит предварительную цену и оставляет имя и телефон. Заявка вместе со всем, что он собрал, приходит в Telegram-бот [@jurkupietari_bot](https://t.me/jurkupietari_bot).

## Что здесь лежит

| Файл | Что это |
|---|---|
| `index.html` | Весь сайт одним файлом: страница, стили, конструктор, цены |
| `assets/` | three.js для 3D и шрифт Inter. Лежат здесь, а не на внешних CDN, чтобы сайт открывался в России без задержек |
| `og.png` | Картинка для превью ссылки в мессенджерах |
| `CNAME` | Домен для GitHub Pages |

Здесь только клиентская версия. Чертежи, экономика, список инструмента и закупочные цены в этот репозиторий не попадают.

## Как поменять цены и контакты

1. Открыть https://jurkujurku.com/#setup. Этот адрес знает только владелец.
2. Поменять цены, телефон, Telegram, при необходимости переподключить бота.
3. Нажать «Скачать готовый index.html».
4. На GitHub: Add file → Upload files → перетащить скачанный `index.html` → Commit changes. Через минуту сайт обновится.
